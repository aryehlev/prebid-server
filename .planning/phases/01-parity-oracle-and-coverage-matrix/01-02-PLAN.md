<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fixture file path -> loader | Untrusted fixture paths can attempt traversal outside the approved corpus |
| Go test process -> Rust bridge process | Untrusted argument handling can turn fixture paths into command injection or incorrect cargo invocation |
| raw diff output -> committed repo summaries | Full payload dumps can leak more data than the matrix needs to track |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | T/E | `parity/oracle/auction.go` cargo bridge | mitigate | Use `exec.CommandContext` with explicit argv entries, fixed repo-root working directory, and a single validated fixture-path argument; do not invoke a shell |
| T-01-05 | T | `parity/oracle/normalize.go` | mitigate | Hard-code the normalization allowlist to warning ordering, seatbid or bid ordering, and fixture-token-generated IDs only; make all other drift emit mismatches |
| T-01-06 | I | `parity/out/auction/*` and index summaries | mitigate | Keep raw case artifacts under ignored `parity/out/`; emit only sanitized metadata and JSON paths into the committed summary/index inputs |
</threat_model>
